# AI 研究日報網站 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Wikipedia-styled single-file reader site for `digests/`, published via GitHub Pages.

**Architecture:** One `index.html` with inline CSS and one inline `<script>`. Pure helpers (date, filter, search) are separate from DOM rendering; state lives in one `state` object and every change calls `render()`.

**Tech Stack:** HTML/CSS/vanilla JS, no dependencies. `python3 -m http.server` for local preview; Chrome for verification.

**Spec:** `docs/superpowers/specs/2026-10-19-website-design.md`

## Global Constraints

- Single `index.html`; no external scripts, fonts or stylesheets.
- Never write to `digests/` or `scripts/`; `python3 scripts/publish.py --check` must print `OK`.
- UI copy in Traditional Chinese; digest content shown as-is.
- Data inserted via `textContent` only.
- Colors: link `#3366cc`, visited `#6b4ba1`, border `#a2a9b1`, subtle bg `#f8f9fa`, text `#202122`; dark: bg `#101418`, text `#eaecf0`, link `#88a3e8`.
- Heading font `'Linux Libertine','Georgia','Times',serif`.
- localStorage access always wrapped in try/catch.

## Review Focus

- Hash names a date not in the index → notice + fall back to newest.
- Opened via `file://` → fetch fails; show the local-server hint, not a blank page.
- Item without `result` / `authors` / `arxiv_id` → those subsections simply absent.
- Search with multiple spaces / mixed case → tokens split on whitespace, all must match, case-insensitive.
- Narrow (360px) viewport → no horizontal scroll; sidebar becomes a `<select>`.
